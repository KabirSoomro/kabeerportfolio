## 📖 About The Portfolio

This repository hosts the personal portfolio of **Kabeer Soomro**, a passionate **Front-End Developer** and **BSCS undergraduate**. 

Designed with an obsession for sleek aesthetics, the website highlights modern UI/UX design trends including **glassmorphism**, dynamic **aurora glowing backdrops**, interactive **3D tilt physics**, smooth scroll animations, dark/light theme switching, and seamless client-side contact delivery via **EmailJS**.

---

## ✨ Standout Features

- 🎨 **Modern Glassmorphism & Aurora UI:** High-contrast, clean typography, glowing ambient lighting, and fluid motion design.
- 🌓 **Instant Dark / Light Mode Toggle:** Smooth transition with persistent user preference storage.
- 📱 **100% Fully Responsive Layout:** Pixel-perfect presentation across smartphones, tablets, and ultra-wide desktop screens.
- 🧊 **3D Tilt Micro-Interactions:** Immersive card hovering effects powered by `Vanilla-Tilt.js`.
- ⚡ **Working Contact Form:** Client-side email forwarding powered directly by **EmailJS** without requiring a dedicated backend server.
- 🔔 **Interactive Alerts & Modals:** Rich animated feedback utilizing **SweetAlert2**.
- 📊 **Animated Skill Gauges:** Real-time visual progress bars tracking frontend and software competencies.

## ⚡ Getting Started Locally

This portfolio requires **no build step** or heavy dependencies. You can run it instantly:

### 1. Clone the repository
```bash
git clone https://github.com/KabirSoomro/kabeerportfolio.git
cd kabeerportfolio
```

### 2. Open in Browser
- Simply double-click `index.html` to open it in your browser.
- **Or** run a lightweight local web server:
```bash
# Using Python
python -m http.server 3000

# Or using Node / npx
npx serve .
```

## 📧 EmailJS Contact Form Setup

To link the contact form to your own inbox:

1. Register at [EmailJS](https://www.emailjs.com/).
2. Create an **Email Service** (e.g., Gmail) and copy your `Service ID`.
3. Create an **Email Template** with variables: `{{name}}`, `{{email}}`, and `{{message}}`.
4. In `index.html`, verify the EmailJS Public Key in the init script:
   ```javascript
   emailjs.init("YOUR_PUBLIC_KEY");
   ```
5. In `script.js`, ensure your `SERVICE_ID` and `TEMPLATE_ID` match your dashboard.
